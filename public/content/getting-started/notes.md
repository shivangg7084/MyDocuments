# Notes Example

A second markdown file in the same folder, so you can see how the folder page
lists multiple files alongside the README.

## Why a manifest?

GitHub Pages serves static files only — there's no server-side code that can list
a directory at runtime. The `content-manifest.json` file generated by
`scripts/generate-content-manifest.ts` is what lets the app know which folders and
files exist, without ever hitting a backend.
