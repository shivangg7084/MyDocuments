# Linear Regression

Linear regression models the relationship between a dependent variable and one
or more independent variables using a straight line.

## Formula

```
y = mx + c
```

Where `m` is the slope and `c` is the intercept.

## Example

Given a dataset of house sizes and prices, linear regression finds the
best-fitting line that predicts price from size.

- Minimizes squared error
- Assumes a linear relationship
- Sensitive to outliers
